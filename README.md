# Low-Level Design (LLD) in C++

This repository is dedicated to simple Low-Level Design (LLD) C++ code for personal practice.

## 🚀 Overview

It contains various object-oriented programming (OOP) practice implementations of classic low-level design problems.

## 🛠️ How to Run

To compile and run any of the C++ files, use a modern C++ compiler (supporting C++17 or later):

```bash
g++ -std=c++17 <filename>.cpp -o <output_name>
./<output_name>
```
